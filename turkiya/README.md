# تركيّة — تعلّم التركية بالعربية

تطبيق ويب تقدمي ثابت لتعلّم **التركية القياسية المعاصرة في تركيا** بواجهة عربية. لا يحتاج إلى حساب أو خادم أو قاعدة بيانات سحابية؛ يحفظ بيانات المتعلم محلياً في IndexedDB.

## محتوى هذه النسخة

تتضمن الخريطة مستويات Pre-A1 إلى C2، و14 درساً تركياً مكتوباً فعلياً (درسان في كل مستوى)، و29 حرفاً مع ملاحظات نطق وتمارين تمييز سمعي، و51 مفردة في 17 موضوعاً، و14 قاعدة تركية، ومواد قراءة واستماع وكتابة وتحدث مرتبطة بالدروس. تشمل الوظائف مراجعة متباعدة محلية، واختبارات قصيرة مع حفظ النتائج، وبحثاً وفلاتر ومفضلة، ولوحة تقدم وXP وسلسلة تعلم وهدفين يومياً وأسبوعياً ونسخاً احتياطياً JSON.

**هذه حزمة محتوى أولية وليست منهجاً مكتملاً من الصفر إلى C2، ولا شهادة CEFR.** عدد الدروس محدود إلى درسين في كل مستوى؛ يلزم إعداد ومراجعة دروس أكثر وتوسيع أنواع الاختبارات ومواقف التواصل لتغطية كامل النطاق المطلوب.

## الصوت والخصوصية

لا يتضمن هذا الإصدار تسجيلات لمتحدثين أصليين. أزرار النطق تستخدم `SpeechSynthesis` في الجهاز عند توفر صوت تركي؛ وقد لا يوجد صوت `tr-TR` في بعض المتصفحات، والصوت الآلي ليس تسجيلاً طبيعياً. وقد يتيح المتصفح `SpeechRecognition` للاستماع إلى نطقك بتقدير تقريبي، وقد يتطلب إذن الميكروفون. يختلف التعامل مع الصوت بحسب المتصفح ومزود الخدمة، فراجع سياسة خصوصية المتصفح قبل استخدام التعرف الصوتي. تسجيل Shadowing مؤقت في الجلسة ولا يُرفع إلى خادم التطبيق، ويُوقف عند مغادرة القسم أو إخفاء الصفحة.

لا توجد حسابات أو مزامنة سحابية أو خدمة تقييم ذكية. تُحفظ المفردات والتقدم والنتائج والإعدادات والمراجعة والمفضلة على المتصفح الحالي. صدّر نسخة JSON قبل مسح بيانات المتصفح أو الانتقال إلى جهاز آخر. الاستعادة تستبدل بيانات الجهاز؛ تُرفض النسخة غير المكتملة أو غير المتوافقة قبل تغيير المخازن، لذا صدّر بياناتك الحالية أولاً.

## حجم المشروع

لا يستهدف هذا الإصدار 30MB؛ لم تُضف تسجيلات أو صور مكررة أو ملفات اصطناعية لزيادة الحجم. الأصول المرئية محدودة لصالح التحميل السريع والعمل دون اتصال. إذا أضيفت لاحقاً تسجيلات تعليمية أصلية أو وسائط ضرورية، يُحدّث Service Worker لتخزينها صراحة.

## التشغيل محلياً

يتطلب Service Worker وPWA سياق HTTPS أو localhost؛ لا تفتح `index.html` مباشرة عبر `file://`.

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. في المعاينة يعمل خادم الملفات على المنفذ 3000.

## النشر على GitHub Pages

1. ارفع محتويات مجلد المشروع إلى جذر مستودع GitHub أو إلى مجلد `/docs`. وإذا كان المستودع يحتوي موقعاً قائماً، ضع التطبيق في مجلد فرعي مستقل بدلاً من استبدال `index.html` الحالي.
2. من **Settings → Pages**، اختر الفرع والمجلد اللذين يحتويان `index.html`، ثم احفظ.
3. انتظر نشر GitHub Pages وافتح الموقع عبر رابط HTTPS؛ Service Worker لا يعمل على HTTP غير الآمن.
4. استخدم التطبيق مرة واحدة مع الاتصال ليخزن غلافه وبيانات المنهج في Service Worker، ثم اختبره دون اتصال.
5. يدعم Chrome المتوافق مطالبة تثبيت عند توفر شروطه. على iPhone/iPad استخدم مشاركة Safari ثم **إضافة إلى الشاشة الرئيسية** إذا لم يظهر زر تثبيت؛ تُرفق أيقونة `apple-touch-icon` بمقاس 180 بكسل.

المسارات نسبية؛ لذلك يدعم المشروع النشر تحت مسار مستودع مثل `https://username.github.io/repository/` دون إعادة كتابة المسارات. يستخدم التنقل مسارات hash داخل الصفحة لتفادي إعدادات rewrite على الاستضافة الثابتة.
في موقع **لغتي** الحالي، يُضاف هذا التطبيق في `turkiya/` ليكون متاحاً من مسار فرعي مستقل، مع الحفاظ على الصفحة الرئيسية ومحتوى الموقع السابق.

## تحديث المحتوى

- بيانات المستويات والدروس في `data/levels/{pre-a1,a1,a2,b1,b2,c1,c2}.json`.
- المفردات في `data/vocabulary/index.json`، والقواعد في `data/grammar/index.json`.
- وحدة الأبجدية والنطق في `js/alphabet.js`؛ الوحدات التعليمية في `js/`.
- حافظ على `id` ثابتاً لكل مفردة ودرس وقاعدة حتى لا تنفصل المراجعات والمفضلة عن عناصرها.
- حقول السؤال الأساسية هي `questionAr` و`options` و`correctIndex` (فهرس يبدأ من صفر) و`explanationAr`.
- بعد إضافة ملفات بيانات جديدة، أضفها إلى `SHELL_FILES` في `service-worker.js` وارفع `CACHE_VERSION` كي تصل للمستخدمين نسخة جديدة. عند ظهور إشعار تحديث، احفظ التقدم ثم أعد تحميل الصفحة لتطبيق النسخة.
- لا تضف أمثلة مكررة لمجرد تكبير المشروع، ولا تضع أسراراً أو بيانات خاصة داخل JSON العام.

## الهيكل

```text
index.html                 غلاف RTL والتنقل
manifest.webmanifest       خصائص التثبيت ومسارات نسبية
service-worker.js          تخزين الغلاف والمحتوى والعمل دون اتصال
manus-routes.json          بيان مسار الصفحة للمعاينة
README.md                   تعليمات التشغيل والنشر وتحديث المحتوى
css/                        الألوان والمكونات ونقاط التوقف
js/                         التطبيق وIndexedDB والمحتوى والتقييم والصوت
  alphabet.js               الأبجدية وتمارين تمييز الأصوات
  lessons.js / skills.js    الدروس ومختبرات المهارات
  spaced-repetition.js      مواعيد المراجعة المحلية
  progress.js / database.js التقدم والتخزين والنسخ الاحتياطي
data/                       مستويات ودروس ومفردات وقواعد
assets/icons/               SVG وأيقونات PWA بمقاسات 180 و192 و512
assets/images/              أصل بصري محلي
```
