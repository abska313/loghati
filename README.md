# لغتي — منصة إتقان اللغات

منصة PWA لتعلم اللغات من الصفر إلى الإتقان.

## اللغات المدعومة
- 🇮🇷 الفارسية
- 🇹🇷 التركية
- 🇪🇸 الإسبانية

## الميزات
- اختبار تحديد مستوى ذكي
- نظام تكرار متباعد (SRS)
- مفردات، قواعد، استماع، قراءة، تحدث، كتابة، ترجمة
- محادثة تفاعلية (محرك محلي بدون API)
- شهادات قابلة للتنزيل
- يعمل دون إنترنت بعد أول تحميل
- دعم RTL/LTR
